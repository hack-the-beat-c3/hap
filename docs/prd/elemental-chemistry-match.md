## 1. 개요 및 해결할 파티 문제

### 1.1 해결할 문제
파티에서 타로 1장 승부 후 어색해진 참가자들에게 **"내가 말을 걸어야 할 사람"**과 **"자연스러운 대화의 명분"**을 제공하여 현장 네트워킹의 병목을 해결합니다.

### 1.2 핵심 가치 (Core Value)
1. **부족 오행 기반 인연 지목**: 내 사주에서 부족한 기운을 가진 파티원 1~3명을 지목하고 맞춤형 미션 제공.
2. **1:1 현장 QR 사주 궁합**: 1:1로 만났을 때 QR을 스캔하여 두 사람만의 시너지 스코어(75~99점)와 아이스브레이킹 대화 주제를 즉석 확인.
3. **완벽한 개인정보 보호**: 원본 생년월일/시각은 서버에 저장하거나 전송하지 않으며 클라이언트에서 오행 수치만 계산.

## 2. 3단계 사용자 흐름 (User Flow)

```
[1단계: 호스트 룸 생성 & 게스트 입장]
       │
       ▼
[2단계: 사주 오행 계산 및 타로 1장 배분]
       │
       ▼
[3단계: 동시 공개 및 리캡 화면]
       ├─ [최강 운세 우승자 발표]
       ├─ [오행 보완 케미 카드]: 내 부족 오행 + 지목된 파티원 1~3명 + 미션 문구
       ├─ [1:1 현장 QR 매칭]: 내 QR 제시 / 상대방 스캔 ➔ 1:1 궁합 리포트 & 대화 카드
       └─ [소셜 공유 카드]: 타인 닉네임 마스킹 안전 공유
```

## 3. 세부 기능 및 규칙

### 3.1 부족 오행 산출 (`pickDeficientElement`)
- 사주 5행 `{ 木, 火, 土, 金, 水 }` 중 최솟값 선택.
- 동률 시 `木 → 火 → 土 → 金 → 水` 우선순위.
- 5행 동일 시 `土` 선택 및 완전 균형형(`isBalanced: true`) 처리.

### 3.2 상생 4종 관계 분류 (`classifyRelation`)
- `채움(complement)`: 상대가 내 부족 오행을 가짐
- `밀어줌(generate)`: 내 주 오행이 상대 주 오행을 생함
- `받음(support)`: 상대 주 오행이 내 주 오행을 생함
- `닮음(mirror)`: 동일 주 오행

### 3.3 1:1 현장 QR 사주 궁합 매칭 (`calculateSynergyMatch`)
- QR 페이로드: `{ version: 1, id, nickname, primaryElement, elements, timestamp }` (생년월일 제외)
- 75~99점 긍정 스코어 + 시너지 타이틀 + 맞춤형 대화 질문 2선

---

## 4. 수용 기준 (Acceptance Criteria)

1. 2인 룸부터 15인 룸까지 빈 화면이나 에러 없이 결정론적으로 동작.
2. 부족 오행 보유자가 0명일 때 상생/닮음 관계로 fallback.
3. 공유 카드에서 타인 닉네임 마스킹 보장.
4. Vitest 단위 테스트 100% 통과 및 모바일(390x844) / 데스크톱(1440x900) 뷰포트 지원.
