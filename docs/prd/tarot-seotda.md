## 제품 계약

- 타깃: 파티 현장에서 모바일 브라우저로 짧은 개인 콘텐츠를 즐길 참가자
- 문제 가설: 회원가입이나 긴 설문 없이 바로 보여주고 공유할 결과물이 필요하다.
- 가치: 생년월일 입력부터 사주+타로 결과 PNG까지 한 흐름으로 끝낸다.

## 영역 정의

김형준은 **사주 확인 뒤 CTA부터 타로 한 장 공개·해설·결과 PNG 다운로드까지**를 핵심 소유한다. 다른 영역이 준비되지 않아도 데모가 완주되도록 히어로·동의·생년월일·간이 사주 확인은 최소 래퍼로 함께 제공한다.

```text
핵심 소유: 타로 22장 → 1/22 한 장 추첨 → 결과 → PNG
최소 래퍼: 동의 → 생년월일 → 오늘의 간이 사주 확인
완료 경계: 사용자가 결과 PNG를 내려받음
```

## 반드시 만든다

1. 필수 동의와 `<input type="date">` 입력
2. `생년월일 기반 오늘의 간이 사주` 확인 화면
3. `타로카드로 오늘의 행운 1장 뽑아보기` CTA
4. 메이저 아르카나 22장 이미지·이름·해설 데이터
5. Web Crypto 기반 세션당 한 번, 카드별 `1/22` 추첨
6. 카드+사주 결과 화면과 Canvas `1080×1350` PNG 다운로드

## 22장 이미지 계약

- 대상: 메이저 아르카나 `0~21` 카드 앞면 22개
- 형식: 동일한 `2:3` 세로 비율, HD급(`1024×1536` 이상), PNG 원본
- 콘셉트: 전통 타로의 대표 상징·구도를 유지하되 **단원 김홍도의 조선 풍속화식 필선·인물 동세·담채·한지 질감**으로 재해석
- 통일 요소: 동일 테두리, 먹색·황토·쪽빛·주홍 팔레트, 모바일에서도 알아보이는 중심 인물과 상징
- 텍스트: 생성 이미지에는 넣지 않고 앱이 카드 번호·한글명·영문명을 오버레이
- 금지: 워터마크, 로고, 카지노·도박 이미지, 현대 물건, 카드별 화풍 불일치
- 파일명: `00-the-fool.png`부터 `21-the-world.png`까지

## 만들지 않는다

- 인터넷 도박, 족보, 순위, 승패, 베팅, 결제, 재추첨
- 호스트·게스트, 룸, PIN/QR, 실시간 기능
- 회원·백엔드·DB·분석 도구·브라우저 영속 저장
- 완전한 사주팔자 또는 과학적 예측 주장
- 새 UI·상태관리·DOM 캡처 의존성

## 완료 기준

- 모바일과 데스크톱에서 위 흐름을 처음부터 끝까지 한 번 완주한다.
- 성공한 흐름에는 `DrawResult`가 하나뿐이고 모든 카드의 이론 확률은 `1/22`다.
- 카드 이미지·이름·해설과 사주 요약이 화면과 PNG에 함께 나온다.
- 22개 이미지가 모두 같은 크기·테두리·화풍이고 카드별 핵심 상징을 육안으로 구분할 수 있다.
- 생년월일은 카드 확정 후 DOM·상태에서 사라지고 Network·URL·Storage·로그에는 한 번도 기록되지 않는다.
- 오류가 나도 임의 사주·`Math.random()` 대체·두 번째 카드를 만들지 않는다.
- 배포 URL과 브라우저 증거를 `docs/QA_EVIDENCE.md`에 남긴다.

## 구현 상한

기존 React·TypeScript·Vite 안에서 `App`의 네 상태와 로컬 함수만 사용한다. 실제 통합 요구가 생기기 전에는 API 계층, 저장소, 전역 store, adapter, factory를 추가하지 않는다.
