# PRD — 타로섯다 파티 운빨 매치

- Owner: 김형준 (`@procloudkim`)
- Status: Optional Add-on / Proposed
- Related ADR: [`ADR-0003`](../adr/ADR-0003-party-luck-dashboard.md)

## 한 줄 정의

개인 운세 결과를 모아 누가 어떤 카드를 뽑았고 오늘 누구의 운빨과 궁합이 좋은지 보여주는 선택형 파티 대시보드다.

## 사용자 흐름

1. 참가자가 기존 개인 운세 카드 한 장을 뽑고 공유에 동의한다.
2. 대시보드가 `닉네임·오행·카드·1~22위 하우스 순위`를 보여준다.
3. 두 사람을 선택하면 카드 운빨 승부와 오행 궁합을 별도로 보여준다.
4. 전체 결과에서 최강 운세, 최강 케미, 상극 케미를 표시한다.

## 규칙

- 카드 순위는 전통 타로 서열이 아닌 파티 하우스 룰이다.
- 낮은 순위 숫자가 더 강하며 같은 순위는 공동 결과다.
- 카드가 승부를, 오행이 궁합 설명을 결정한다. 둘을 합산하지 않는다.
- 정확한 생년월일은 전송·표시하지 않는다.
- 베팅·현금 보상·결제·유료 재추첨은 없다.

## 완료 기준

- 개인 운세 기능은 대시보드 없이도 완주된다.
- 참가자 2명 이상에서 전체 순위와 1:1 매치가 표시된다.
- 상생·상극·동행 결과가 입력 순서와 무관하게 같다.
- 동일 카드에는 임의 승패를 만들지 않는다.
- 원본 생년월일과 도박 표현이 대시보드에 없다.
